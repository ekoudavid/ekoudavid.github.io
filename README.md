# David Ekou: personal website

Portfolio site for David Ekou, MEAL Officer, Kampala, Uganda.

## Files
- `index.html`: the whole site (HTML, CSS and JS in one file)
- `cv.pdf`: public CV (referee contacts removed)
- `photo.jpg`: optional. Add a square headshot with this exact name and it replaces the "DE" initials.

## Deploy on GitHub Pages
1. On GitHub, create a new **public** repository named exactly `ekoudavid.github.io`.
2. Upload `index.html`, `cv.pdf` (and `photo.jpg` if you have one) to the repository root and commit.
3. Go to Settings > Pages and make sure the source is "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute or two the site is live at https://ekoudavid.github.io

## Updating
Edit `index.html` and commit. Each project is an `<article class="proj">` block; copy one to add a new project.
